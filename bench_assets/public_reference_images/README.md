# Public reference image transport

The PNG is an unchanged copy of the public shrine image selected for the H3
REF2VA experiment. It is served separately from the frozen runtime archive so
the benchmark does not depend on Wikimedia accepting requests from Kaggle.

- Creator/uploader: Benlisquare, 29 September 2022.
- [Original file and licensing](https://commons.wikimedia.org/wiki/File:Algorithmically-generated_landscape_artwork_of_forest_with_Shinto_shrine.png).
- Original dimensions: 4096 x 2048; original bytes: 7,703,256.
- SHA256: `cd4cbfd7137b80e85e64ada86ffd93e512b874de84cb4291fc0278b747461e03`.

The original file's licensing applies to this image; the project software
license does not replace it. There is no resizing, re-encoding or pixel change.
The benchmark uses a raw GitHub URL pinned to the commit containing this file
and verifies the original byte count and hash before loading it.
