## Persisted baking rather than inference-time CPU merging

`patches/tp2_disk_bake.py` reconstructs each affected full-width Native matrix
from the original two rank shards. It applies the ordered Native FP32 adapter
merge, independently checks the result, performs full-width ConvRot/INT8
quantization, and only then splits both output owners. Row-parallel scales
remain full-width/shared; component-packed QKV/FC1 row ownership is preserved.

Whole DiT layers are assigned to two GPU worker processes; each matrix is baked
once. Token Refiner replacements are written into a separate auxiliary file.
Both owners, auxiliary weights, state hashes and a version/source-bound recipe
are persisted before atomic descriptor publication. A failed bake leaves an
unpublished partial directory and never a valid inference descriptor. Reusing
a cache with a different base, adapter, strength or bake environment is rejected.

`DiskBakedReader` validates the persisted files and their original base proofs.
It never attaches online LoRA and has zero merge workspace. Unit tests remove
the test's original rank payloads after baking and prove that repeated block
loads still match the independent Native merge without calling the merger.
The two-process CPU check also validates shard writes, flush, publication and
worker termination; it does not qualify GPU math.

To bound disk usage, the job downloads only DiT first, bakes it, then deletes
only its own verified DiT download copies before fetching TE/VAE weights. The
pinned HF revision is unchanged. Missing Native auxiliary tensors are read
from pinned original-file ranges; the complete source DiT is never downloaded.

The disk cache is `/kaggle/temp/h3_l1_turbo_05mp/baked_tp2`. It survives worker
and residency-window eviction during this instance. It is not automatically
uploaded or preserved after the Kaggle VM is destroyed. Bake receipts and
hashes, generation media and sampling latents are notebook outputs; approximately
20GB of baked weights are not added to artifact collection.
