## Disk, memory and delivery

The job downloads original pre-sliced DiT shards first, performs one regular
Turbo bake on both GPUs, persists 100 output shards and auxiliary state, then
releases only its own complete original DiT payload copies. TE and VAEs follow.
It never caches eight PTD experts. The earlier regular bank occupied about
19.78 GiB; the staged ordinary workflow is substantially smaller than the
roughly 170-GiB full PTD bank. The recently measured root-overlay write boundary

added to this generation job.

reference bytes are hash-checked: the character JPEG is staged inside the
private notebook, and the shrine PNG uses its previously qualified immutable

job requires this new capsule's matching successful CPU setup and workload
receipts. Frozen legacy ComfyUI and exact core pins are unchanged: Kitchen

One GPU request is authorized. Setup has a 600-second watchdog; execution has
