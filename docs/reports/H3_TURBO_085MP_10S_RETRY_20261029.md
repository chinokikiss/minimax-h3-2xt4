## Version 2 changes

The workload and production runtime are unchanged. The benchmark downloader now
allows **three total attempts** for HTTP 408/429/500/502/503/504 and transport
connection/timeouts, with **5 s and 15 s** backoffs. It reuses HF's existing
partial-download/cache directory. Only the transient fetch is retried; exact
revision, byte size and SHA256 verification remain mandatory. Authorization,
integrity and other nontransient errors fail immediately. Retry receipts contain
filename, exception type, HTTP status and delay, without signed URLs.

This handling covers TP2 shards, the LoRA and VAE checkpoint downloads through
the shared HF helper. It does not change auxiliary range-assembly behavior or
the library's internal timeout budget. The existing overall watchdog remains.
Isolated mocked checks exercised recovery, retry exhaustion and fail-fast
behavior without network/model execution or a CPU smoke run.
